# 다올코인 (다올 마켓 교환권)

중학교 행사 「다올 마켓」에서만 쓰는 종이 교환권 도안입니다. 실제 화폐가 아닙니다.

- **번호 인쇄 페이지:** https://dallalan2277-lab.github.io/daol-coin/ — 열고 [인쇄]. 기본 800장(1코인 430 · 2코인 180 · 5코인 190), A4 80쪽, 번호 001~800
- `blank-a4.html`: 번호 없는 A4 견본 (권종별 1쪽)
- `basket-1.svg`, `basket-2.svg`, `basket-5.svg`: 한 장 도안 (90 × 50 mm)

인쇄 설정: A4 세로 · 배율 100%(실제 크기) · 여백 없음 · 머리글·바닥글 끄기.
만드는 순서: 인쇄 → 도장 → A4째 코팅 → 자르는 선대로 자르기.
